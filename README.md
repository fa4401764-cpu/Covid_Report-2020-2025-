# COVID Report 2020–2025

1- Project Title:                                                                            
COVID-19 Global Analysis Dashboard 2020–2025                                                                                       

2- Short Description:                                                                                      
A dynamic and interactive COVID-19 dashboard built in Power BI to analyze global pandemic statistics from 2020 to 2025. The dashboard provides insights into total confirmed cases, deaths, recoveries, vaccination progress, recovery rates, and country-wise COVID trends through interactive visualizations and KPI metrics.                                                                                 
The project transforms complex healthcare data into an easy-to-understand analytical dashboard for monitoring pandemic impact and global health trends.                                                                                     

3- Tech Stack:                                                      
• Power BI Desktop – Dashboard development & visualization                                                       
• Power Query – Data cleaning and transformation                                                                   
• DAX (Data Analysis Expressions) – KPI calculations and measures                                                                 
• Excel / CSV Data Handling – Data preparation                                                                                   
• Data Visualization Techniques – Charts, KPI cards, maps, slicers, and filters 

4- Data Source:                                                                                                      
Global COVID-19 Dataset                                          
Source: Public COVID-19 datasets (WHO / Kaggle / Our World in Data)                                                               

5- Features:                                                  
📊 Interactive Dashboard Navigation :                                                                  
• Interactive dashboard with multiple analytical sections                                                             
• Easy navigation using slicers and filters                                                                                 
Month-wise filtering for customized analysis                                                        

🌍 Global COVID-19 Analysis:                                                                      
• Tracks pandemic indicators such as: Confirmed Cases , Deaths, Recoveries, Vaccination Statistics,Recovery Rate Percentae                
• Provides quick insights into global ;pandemic trends and healthcare statistics.                                         

🏥 Country-wise COVID Analysis:                                                   
• Compares new cases and recoveries among different countries                                                        
• Displays total cases and deaths by country                                                                
• Helps identify highly affected regions and recovery performance                                   

📅 Yearly Trend Analysis:                                                              
• Analyzes COVID-19 statistics across different years.                                                                 
• Displays:                                                      
Recovery Rate by Year                                                      
Death Rate by Year                                                                
Case Trends Over Time                                                                                      
Vaccination Progress                                                                       
• Useful for trend forecasting and pandemic impact analysis.                                                            

🔍 Interactive Filters:                                                                             
• Users can filter data by months and years                                                                    
• Dynamic visuals automatically update based on selected filters                                                                       
• Improves user interaction and customized reporting                                                                    

📌 KPI Summary Cards:                                                  
• Displays important COVID-19 indicators including: Cases ,Deaths ,Vaccinated ,Recovery Rate ,Last 7-days Average Cases                        
• Provides quick analytical insights and performance monitoring.

📉 Visual Analytics:
• Includes multiple visualization types such as:                                                                                        
Bar Charts                                                      
Line Charts                                                                          
Donut Charts                                                                 
Maps                                                 
KPI Cards                                                         
Slicers and Filters                                         
Makes complex healthcare data easier to interpret and analyze.
